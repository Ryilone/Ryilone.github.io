04

OSINT Panel

A terminal toolkit for looking things up from public sources.

Role
Solo
Platform
Command line and terminal dashboard
Status
v1.2
Built with
Python, Rich, Textual, httpx, dnspython

The problem

Public-source research means juggling a dozen websites, and half of them give you a wrong answer without saying so.

I wanted one fast tool with honest results, output I could pipe into other tools, and a dashboard for when I'd rather not remember flags.

What I built

  • Five modules: usernames across 50+ sites, email, domain, IP and phone numbers.
  • One pipeline, many outputs. Each module gathers its data once and returns a structured result that renders as a Rich table, feeds the Textual dashboard, or exports to JSON, CSV or a standalone HTML report.
  • Domain lookups that work on filtered networks. DNS runs over HTTPS by default, and subdomains come from both a wordlist and certificate transparency logs, resolved concurrently with a sensible cap.

The hard part

Not lying about matches

Most username checkers treat any page that loads as "found". That breaks in two ways: bot walls like Cloudflare's "Just a moment…" page look like a profile, and some sites return the same page whether an account exists or not.

Every site check here returns one of five states: found, not found, blocked by a bot wall, unknown for sites that can't be checked reliably, or error. I built each site's markers from live probes. With a made-up handle the tool reports zero matches, and on a well-known account it separates 20 real matches from 16 bot walls instead of counting all 36.

The tool only reads what's publicly visible. It never logs in, and it doesn't try to get past a bot wall. It reports the wall and moves on.
