01 Shipped · Build 17

MacroMaxx

A macro tracker that runs natively on my iPhone, and works offline.

Built in SwiftUI with the full USDA Branded Foods database stored on the device in SQLite, so search works without a connection. Barcode scans get a Nutri-Score 2023 grade ported from Open Food Facts. Menus from seven restaurant chains (1,054 items) are parsed straight from their nutrition PDFs. It reads weigh-ins from Apple Health and has a home-screen widget. I've shipped seventeen builds to my phone, and a daily job re-signs the app so it never expires.

  • SwiftUI
  • SQLite
  • HealthKit
  • WidgetKit
  • Python
02 In progress

ClassPath

What class is next, and when do I need to leave?

A campus app for LMU built with Expo and React Native. It keeps your schedule locally in SQLite, combines it with a campus data pack of buildings and walking routes, and tells you when to leave for your next class. It follows a strict design contract: every color has exactly one meaning, and it never shows made-up campus data or uses color as the only signal.

  • Expo
  • React Native
  • TypeScript
  • SQLite
03 Mod · Desktop · macOS

SpotiHUD

What's playing on Spotify, shown wherever I'm looking.

It started as a Minecraft Fabric mod that signs in to Spotify with PKCE and draws the current track on the in-game HUD. It grew into a desktop overlay built with Tauri and Rust, and then a SwiftUI version of the Dynamic Island for the Mac notch. That one's equalizer reacts to the actual music: it captures system audio with Core Audio and splits it into frequency bands with an FFT.

  • Java
  • Fabric
  • Rust
  • Tauri
  • Swift
  • Core Audio
04 v1.2

OSINT Panel

A terminal toolkit for looking things up from public sources.

A Python command-line tool with a Textual dashboard. It looks up usernames across 50+ sites, domains, IP addresses, phone numbers and email addresses. For each site, username checks report one of five results: found, not found, blocked by a bot wall, unreliable, or error. That way a CAPTCHA page never counts as a match. Domain lookups use DNS over HTTPS and find subdomains through certificate transparency logs. Every result can be exported to JSON, CSV or HTML.

  • Python
  • Rich
  • Textual
  • httpx
